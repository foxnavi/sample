# sample
## Python Sample Program

This repository includes two simple Python scripts.

- `hello.py` prints a greeting to the console:

```bash
python3 hello.py
```

- `web.py` starts a local web server and opens a browser window showing the greeting:

```bash
python3 web.py
```

The server runs on http://localhost:8000 and displays "Hello, world!" in your browser.
